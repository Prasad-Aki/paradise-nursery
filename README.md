# Paradise Nursery

Paradise Nursery is a React plant-shopping application where customers can browse indoor plants, add plants to a shopping cart, update quantities, and remove items.

## Features
- Landing page with a background image and Get Started button
- About Us section
- Plant product listing with category filters
- Add-to-cart functionality
- Shopping cart with quantity updates, item removal, and subtotal
- Redux Toolkit state management

## Technologies
- React
- Vite
- React Router
- Redux Toolkit
- React Redux
- CSS

## Run locally
1. Install Node.js (LTS).
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed in the terminal.
